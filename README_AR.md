# MolSolveAI (نسخة نظيفة تعمل)

تطبيق يأخذ صيغة جزيء (SMILES) ويعرض رسمه وخصائصه وتنبؤات الذكاء الاصطناعي.
⚠️ للبحث والتعلم فقط، لا يصلح لقرار علاجي أو دوائي.

## أسهل طريقة: على جهازك (ويندوز/ماك/لينكس)
1. ثبّت بايثون 3.10 أو أحدث من python.org
2. افتح المجلد في الطرفية (Terminal / CMD) ونفّذ:
   pip install -r requirements.txt   (للتشغيل فقط، خفيف بدون torch)
3. شغّل الواجهة (النموذج المدرَّب جاهز داخل checkpoints):
   streamlit run app.py
4. يفتح المتصفح تلقائياً. اختر مثالاً أو اكتب SMILES واضغط «حلّل».

## إعادة التدريب (اختياري، 1 إلى 3 دقائق على جهاز عادي)
   pip install -r requirements-train.txt
   python train.py
البيانات الثلاث عامة ومرفقة في data/raw، وتُحمَّل تلقائياً إن حُذفت.

## على Google Colab (مجاني)
في خلية: !pip install rdkit torch streamlit python-dotenv scikit-learn
ثم ارفع المجلد وشغّل: !python train.py
(الواجهة streamlit تحتاج نفقاً مثل ngrok، الأسهل تشغيلها على جهازك.)

## ماذا يتنبأ؟
- محسوبة بدقة مباشرة من RDKit (بلا ذكاء اصطناعي): الوزن الجزيئي، LogP، TPSA، HBD، HBA، الروابط الدوّارة، ومخالفات قاعدة ليبنسكي.
- من الذكاء الاصطناعي: الذوبانية LogS (بيانات ESOL)، عبور الحاجز الدموي الدماغي BBB (بيانات BBBP)، و12 اختبار سمّية (Tox21).
- عدم اليقين (±) حقيقي: يُكرَّر التنبؤ 30 مرة مع تفعيل Dropout ويُقاس تفاوته.
- ما حذفناه بصراحة: hERG وCaco2 والتوافر الحيوي لأنه لا توجد لها بيانات مرفقة هنا، وإظهار أرقام لها كان سيكون وهماً.

## جودة النموذج (على جزيئات بهياكل لم يرها أثناء التدريب)
- الذوبانية: خطأ RMSE ≈ 1.18 وحدة LogS، و R² ≈ 0.71
- عبور الحاجز الدموي: AUC ≈ 0.96
- السمّية (12 اختبار): AUC متوسط ≈ 0.77 (من 0.65 إلى 0.85)
هذه أرقام جيدة لنموذج صغير، لكنها ليست مرجعاً سريرياً.
